## La regla que este documento existe para hacer cumplir

**Ningún piloto empieza en [NOMBRE DE LA ORGANIZACIÓN] hasta que la Sección 3
esté llena y firmada.** La mayoría de los pilotos grandes de IA no tienen una
condición de alto por escrito, y precisamente por eso nunca paran: se vence la
ventana, la herramienta sigue instalada, nadie decide nada, y un piloto se
convierte en una adopción por descuido. La condición de alto de abajo es un
campo obligatorio, no una sugerencia, y quien aprueba la firma antes del primer
día, no después del último.

Las organizaciones grandes hacen pilotos. No hacen despliegues. Una sede, un
responsable, una ventana.

## 1. Registro del piloto

Lo llena el responsable del piloto y lo entrega al
[RESPONSABLE DE GOBERNANZA DE IA] antes de la fecha de inicio. La herramienta se
anota ese mismo día en el Registro de Herramientas Aprobadas como **en piloto**.

| Campo | Lo que se anota |
| --- | --- |
| Herramienta y proveedor |  |
| Qué se supone que hace por nosotros |  |
| Nivel (1, 2 o 3) |  |
| Quién la aprobó, según la matriz de autoridad |  |
| Sede del piloto — una sola |  |
| Responsable del piloto — una persona con nombre, no un puesto |  |
| Fecha de inicio |  |
| Fecha de término — fija, no "en curso" |  |
| Personal incluido (puestos y cuántos) |  |
| ¿Toca información que nombra a un niño o a una familia en particular? |  |
| ¿Hay acuerdo por escrito en el archivo? ¿Dónde? |  |
| Consentimientos requeridos y obtenidos (Nivel 3) |  |
| Qué pasa con los datos cuando termina el piloto |  |

Un piloto corre en **una** sede. Si dos sedes lo quieren, la segunda espera la
decisión de cierre de la Sección 5.

## 2. Criterios de éxito, declarados por adelantado

Escríbalos antes de la fecha de inicio. Los criterios escritos después son una
descripción de lo que pasó, no una prueba.

| Qué esperamos | El número que cuenta como éxito | Cómo se va a medir | Quién lo mide |
| --- | --- | --- | --- |
| Tiempo que se le devuelve al personal |  |  |  |
| Calidad del trabajo producido |  |  |  |
| El personal se lo quedaría (proporción que dice que sí) |  |  |  |
| [OTRO CRITERIO] |  |  |  |

Por lo menos un criterio tiene que ser sobre los niños o las familias, y no solo
sobre el tiempo del personal. En los pilotos de Nivel 3, un criterio tiene que
ser si el desempeño se sostiene para los niños que aprenden dos idiomas y para
los niños con discapacidades, porque §1302.102(c)(2) ya exige un análisis
desglosado y un piloto es el lugar más barato para averiguarlo.

## 3. Condición de alto — obligatoria

**Este piloto para de inmediato, sin reunión, si pasa cualquiera de las
siguientes cosas.** No son advertencias. Cada una termina el piloto el mismo día
en que ocurre.

- Información de un niño o de una familia llega a un lugar que el acuerdo por
  escrito no cubre.
- La herramienta produce un resultado que afectaría a un niño en particular —una
  alerta, una puntuación, una sugerencia de referencia— que no era parte del
  alcance aprobado.
- El proveedor cambia los términos, activa una función que no aprobamos, o no
  puede contestar una pregunta de la Hoja de preguntas para proveedores dentro
  de [DIEZ DÍAS HÁBILES].
- Ocurre cualquiera de los usos de las prohibiciones permanentes de la carta de
  gobernanza, o resulta que la herramienta es capaz de hacer uno.
- Una familia se opone y la objeción no se puede atender mientras el piloto
  corre.
- [CONDICIÓN DE ALTO DEFINIDA LOCALMENTE — ESCRIBA UNA]

**Y el final ordinario:** si los criterios de éxito de la Sección 2 no se
cumplen para la fecha de término, el piloto termina en la fecha de término. La
herramienta se desinstala, se quitan los accesos y el renglón del Registro se
cierra. Nada continúa por descuido.

Quién puede pararlo: el responsable del piloto, el director de la sede, el
[RESPONSABLE DE GOBERNANZA DE IA] o cualquier integrante del Grupo de Revisión
de IA, actuando solo. Parar no requiere ninguna aprobación.

## 4. Aviso al personal y a las familias

Los dos avisos salen antes del primer día. Ninguno es un formulario de
consentimiento.

**Al personal de la sede del piloto:** "Del [FECHA DE INICIO] al
[FECHA DE TÉRMINO] vamos a probar [TIPO DE HERRAMIENTA — p. ej. UNA HERRAMIENTA
DE HORARIOS] solo en esta sede. [NOMBRE DEL RESPONSABLE] lo está llevando y es a
quien usted le pregunta. A usted no se le va a evaluar según cuánto la use. Si
la herramienta hace algo raro, llame al [PUESTO DE ESCALAMIENTO] al [TELÉFONO];
esa llamada nunca se le va a echar en cara. Ya dejamos por escrito, de
antemano, qué nos haría quedarnos con ella y qué nos haría pararla, y le vamos a
decir cuál de las dos pasó."

**A las familias de la sede del piloto:** "Entre el [FECHA DE INICIO] y el
[FECHA DE TÉRMINO], nuestra sede [NOMBRE DE LA SEDE] va a probar una herramienta
de computadora que le ayuda al personal con [DESCRIPCIÓN SENCILLA DEL TRABAJO].
[DIGA SI TOCA INFORMACIÓN SOBRE SU HIJO O HIJA, Y DE QUÉ TIPO]. Aquí ninguna
herramienta de computadora decide nada sobre su hijo o hija. Decide una persona.
Usted nos puede preguntar lo que sea sobre esto, y puede pedir ver nuestra lista
de herramientas aprobadas y nuestro acuerdo con esta empresa. Las preguntas van
a [NOMBRE], [PUESTO], al [TELÉFONO] o al [CORREO ELECTRÓNICO]."

En un piloto de Nivel 3, el aviso no basta. Se requiere el consentimiento de los
padres por separado antes de que la información de cualquier niño entre a la
herramienta, y una familia que dice que no conserva los mismos servicios.

## 5. Expediente de la decisión de cierre

Se llena dentro de [DIEZ DÍAS HÁBILES] de la fecha de término, se entrega al
[RESPONSABLE DE GOBERNANZA DE IA] y se le informa a
[JUNTA DIRECTIVA O DUEÑO] en el siguiente punto trimestral. Un piloto sin
expediente de cierre se da por parado.

| Campo | Lo que se anota |
| --- | --- |
| ¿Se cumplieron los criterios? Cuáles, con los números |  |
| ¿Qué criterios no se cumplieron? Cuáles |  |
| Qué dijo el personal |  |
| Qué preguntaron las familias o a qué se opusieron |  |
| Incidentes o llamadas de escalamiento durante la ventana |  |
| **Decisión: adoptar / parar / extender una vez** |  |
| Razones, en dos o tres oraciones |  |
| Si se adopta: nivel, quién aprueba, orden del despliegue, renglón del Registro actualizado |  |
| Si se para: fecha de desinstalación, borrado de datos confirmado por el proveedor el [FECHA] |  |
| Si se extiende una vez: nueva fecha de término, qué es exactamente lo que todavía necesitamos aprender |  |

**Extender una vez significa una vez.** Un piloto se puede extender una sola
vez, por una pregunta declarada que la primera ventana no pudo contestar. No hay
una segunda extensión. Si la pregunta sigue abierta en la segunda fecha de
término, la respuesta es parar.
